Z언어

Z언어은 간단한 문법과 컴파일을 사용하여
빠른 연산을 하게끔 목표가 정해 졌습니다.

현재은 개발 단계로 임시로 인터프리터를
사용 하고 있습니다. 컴파일 기능은 
차후 계발 하겠습니다.

실행 방법은 main.z에 원하는 코드를 입력후
터미널 창에서 Command Prompt를 선택한뒤
cd "c:\파일명"을 적고
python z_runner.py를 입력하세요

혹은 윈도우 검색창에 Developer Command Prompt for VS 
를 관리자 권한으로 실행한뒤 
cd "c:\파일명"을 적고
python z_runner.py를 입력하세요

만약 출력을 했을때 Python 으로 출력이 되면 
파이썬이 안깔려 있거나 깔려 있다면
이썬 3.14 설치 파일(python-3.14.x.exe)을 다시 실행합니다.

Modify 수정를 클릭합니다.

Add Python to environment variables 항목을 체크하고 끝까지 진행 Install해 주세요.


=====================================================================================


기본 적인 문법 입니다


1. 기본 구조 & 주석
기본 함수 (main): 프로그램의 시작점입니다.

주석: // 뒤의 내용은 무시됩니다.

main() {
    // 이것은 주석입니다.
    print("Hello Z Language!\n")
}

=====================================================

box / conda	정수 및 실수 (숫자형)	box x = 10

line	문자열	line msg = "Hello"

bool	논리형 (true / false)	bool flag = true

cpx	복소수	cpx z = cpx(3, 4)


main() {
    box a = 10
    line name = "Z Lang"
    bool isDone = false
    
    // 변수 값 변경 (재할당)
    a = 20
}

========================================================

. 출력문 (print)
괄호 ()는 생략할 수 있으며, 여러 값을 쉼표 ,로 연결해 출력할 수 있습니다. (\n은 줄바꿈 처리)


main() {
    print("숫자: ", 100, "\n")
    print("이름: " , name)
}

========================================================

4. 연산자 (Operators)
산술 연산자: +, -, *, /

비교 연산자: ==, !=, <, >, <=, >=


main() {
    box x = (10 + 5) * 2
    bool isGreater = x > 20
}

=======================================================

5. 조건문 (if, else)
조건식은 괄호 () 안에 작성하며, else if와 else 블록을 지원합니다.


main() {
    box score = 85

    if (score >= 90) {
        print("A 학점\n")
    } else if (score >= 80) {
        print("B 학점\n")
    } else {
        print("C 학점\n")
    }
}

==========================================================

6. 반복문 (for, while)
for 문 (범위 반복)
+(N) 문법을 통해 0부터 N-1까지 반복합니다.


main() {
    // i가 0부터 4까지 5번 반복
    for i in +(5) {
        print("i의 값: ", i, "\n")
    }
}

while 문 (조건 반복)
조건이 참인 동안 계속 반복합니다.


main() {
    box count = 3
    while (count > 0) {
        print("카운트다운: ", count, "\n")
        count = count - 1
    }
}

===========================================================

7. 사용자 정의 함수 & 반환값 (return)
함수 정의: 함수이름(인자1, 인자2, ...)

반환값: return 키워드 사용


add(a, b) {
    return a + b
}

main() {
    box result = add(10, 20)
    print("합계: ", result, "\n")
}

===========================================================

종합 예제 코드 (main.z)

add(a, b) {
    return a + b
}

main() {
    print("=== Z 언어 테스트 ===\n")
    
    // 변수와 연산
    box x = 5
    box y = add(x, 10)
    print("y의 값: ", y, "\n")
    
    // 조건문
    if (y > 10) {
        print("y는 10보다 큽니다.\n")
    }
    
    // 반복문
    print("--- 반복문 실행 ---\n")
    for i in +(3) {
        print("Loop ", i, "\n")
    }
}
